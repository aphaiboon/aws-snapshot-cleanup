# Contributing

Thanks for your interest in improving this AWS snapshot cleanup project! To contribute, fork the repository and create a feature branch off `main`, make your changes to the Lambda code (`lambda/`), Terraform configuration (`terraform/`), or tests (`tests/`) as needed, and ensure `pytest` passes locally before opening a pull request with a clear description of what changed and why. For larger changes — new cleanup rules, IAM policy updates, or infrastructure refactors — please open an issue first to discuss the approach.
